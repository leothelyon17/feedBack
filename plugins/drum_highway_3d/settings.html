3D Drum Highway

Pick a song with a drum tab (sloppak-spec §5.3), choose 3D Drum Highway from the viz picker. The drum profile switcher is shared with the 2D highway. MIDI device mapping lives on the MIDI tab. Bloom, camera, and theme live on the Graphics tab.

Drum profile

Named session (device + highway). Switching a profile refetches that device's MIDI notes. Two drums panels may both switch the same active profile.

No profile active.

3D lane layout

Visual only: add the pieces you actually have, in the order you want them on this highway (left → right). This does not change the MIDI device map (that lives on the MIDI tab). The default fallback routing covers most common kit setups; use the fallbacks panel below to reroute any chart piece to a different lane, or set it to "—" to silently drop it.

Chart fallbacks for pieces I don't have

When a song uses a piece that isn't on your kit, route it to one of your lanes. Set "—" to silently drop that piece.
