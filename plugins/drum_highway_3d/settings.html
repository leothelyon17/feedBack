3D Drum Highway

Pick a song with a drum tab (sloppak-spec §5.3), choose 3D Drum Highway from the viz picker. MIDI kit mapping and the drum profile switcher are shared with the 2D highway. Bloom, camera, and theme live on the Graphics tab.

Drum profile

Named session (kit + input). Switching a profile refetches that kit's MIDI notes. Two drums panels may both switch the same active profile.

Auto-picks the first non-passthrough input on load when a source is enabled. Pick "none" to disconnect; the source stays disabled until you select a device.

MIDI kit mapping

Maps your e-kit MIDI notes onto drum pieces. This is shared with the 2D highway. It is not the 3D lane layout — changing mapping never reorders lanes. Select a kit, then confirm with Use this kit before Learn, edit, or remove can run.

3D lane layout

Visual only: add the pieces you actually have, in the order you want them on this highway (left → right). This does not change MIDI kit mapping. The default fallback routing covers most common kit setups; use the fallbacks panel below to reroute any chart piece to a different lane, or set it to "—" to silently drop it.
